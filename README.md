# CBT Thought Record Tracker

A digital tool for tracking and recording Cognitive Behavioral Therapy (CBT) thought records.

## Features

- 📍 **Location tracking** - Record where you are (Home, Hospital, School, Outside, Other)
- 📌 **Event description** - Describe what happened
- 💭 **Thoughts** - Record thoughts with belief intensity (0-100%)
- 😊 **Emotions** - Track emotions with intensity ratings
- 💪 **Physical sensations** - Interactive body map to mark sensation locations
- 🎯 **Coping behaviors** - Document how you coped
- 📋 **Records history** - View all past entries
- 📊 **Insights dashboard** - See patterns in your emotions and thoughts

## How to Use

1. Open `index.html` in your browser
2. Enter PIN: `1234`
3. Click "New Record" to start a CBT thought entry
4. Fill in each section as you go through the cycle
5. Click "Save Complete Record" when done
6. View your records in "My Records" tab
7. Check "Insights" tab for patterns

## Privacy

All data is stored locally in your browser. Nothing is sent to any server.
